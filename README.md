# Adversarial-Search-and-Games
This repository contains the implementation of Reinforcement Learning algorithms and a  report for Assignment 3 in ICS 381 (Adversarial Search and Games). The project focuses on developing AI agents for Connect-4, including Minimax (AgentA), Expectimax (AgentB), and a Random agent (AgentC), and evaluating their performance.

# Assignment Requirements

Problem Formulation: Define Connect-4 as a search problem (states, actions, transition model, goal test, path cost).

Heuristic Function: Implement and explain a board-evaluation heuristic.

# Agent Implementations:

AgentA: Minimax with alpha-beta pruning (opponent p=1).

AgentB: Expectimax (opponent p<1 parameterizable).

AgentC: Random-move baseline.

# Experimental Evaluation: 
Play 10 matches for each pairing, record win/loss ratios, game lengths, and pruning counts.

# Analysis:
Compute min, max, average, and standard deviation for game length and pruning. Comment on results.
